# Banned Phrases & Language Rules

## Resume Clichés — Instant Red Flags

These phrases appear on millions of resumes. They signal nothing and cost keyword space. Replace with specific evidence or cut entirely.

| Banned | Why | Fix |
|---|---|---|
| Detail-oriented | Every candidate claims this | Show a concrete example of attention to detail or cut |
| Results-driven | Empty — every professional is nominally results-driven | Quantify an actual result |
| Hard worker / Works hard | Sets a very low bar | Don't say it — show it |
| Team player | Says nothing about how you work with teams | Describe cross-functional collaboration in a specific context |
| Self-starter | Another self-reported trait with no evidence | Show initiative through an achievement |
| Passionate about | Vague and unverifiable; overused | Cut; let work speak |
| Dynamic professional | Meaningless filler | Cut |
| Proven track record | Only means something if the track record is specified | Write the record, cut the phrase |
| Synergize / Synergy | Corporate filler from 2005 | Cut |
| Think outside the box | Cliché about avoiding clichés | Cut |
| Go-getter | Cut | Cut |
| Leverage (as a verb for "use") | AI/corporate jargon | Replace with "used", "applied", "built on" |
| Spearhead | Overused; sounds performative | "Led", "Initiated", "Launched" |
| Utilize | Fancier word for "use" that adds nothing | Replace with "use" |
| Facilitate | Vague; hides what you actually did | Replace with the specific action |
| Interface with | Means "talked to" or "worked with" | Replace with "worked with", "partnered with", "reported to" |
| Liaise | Same as above | Replace with direct description |
| Responsible for | Passive; describes a job description, not an achievement | Start with the action verb of what you did |
| Managed a team of | Start with impact, not headcount | "Led [N]-person team to deliver [result]" |
| Assisted with | Vague; minimizes contribution | Describe the specific contribution |
| Helped with | Same as above | Same fix |
| Participated in | Even more passive | What was your specific role? |
| Exposure to | Means "barely touched" — avoid unless genuinely describing limited context | If you used it, say you used it |
| Familiar with | Signals you can't actually use the skill | Either claim it or don't list it |
| Knowledge of | Same issue as "familiar with" | Claim it or cut it |
| Strong communication skills | Universal claim; means nothing without context | Cut or show with specific example |
| Excellent interpersonal skills | Same | Cut |
| Fast learner | Can't be verified; everyone says it | Show via a rapid ramp-up story |

## Weak Verbs — Replace These

Strong resumes open bullets with strong verbs. These are weak — replace them.

**Weak → Strong alternatives:**

| Weak | Stronger options |
|---|---|
| Did | Built, Created, Executed, Delivered, Ran |
| Made | Designed, Developed, Engineered, Produced |
| Worked on | Led, Owned, Drove, Contributed to (only if you were genuinely secondary) |
| Helped | Collaborated, Partnered, Co-developed (be specific about role) |
| Was responsible for | Start with the action you took |
| Handled | Managed, Directed, Oversaw |
| Assisted | Supported, Enabled, Contributed to |
| Involved in | Own the contribution or cut |
| Participated | Led, Contributed, Collaborated |
| Used | Applied, Deployed, Implemented, Built with |
| Learned | Mastered (only if true), Developed proficiency in |
| Ran | Led, Managed, Oversaw, Facilitated |

**Strong opening verbs by category:**

*Leadership:* Led, Directed, Managed, Oversaw, Guided, Mentored, Coached, Built, Scaled, Hired, Grew

*Technical:* Architected, Engineered, Developed, Built, Designed, Implemented, Deployed, Automated, Optimized, Refactored, Migrated, Integrated

*Analysis:* Analyzed, Modeled, Forecast, Identified, Evaluated, Assessed, Quantified, Synthesized, Benchmarked

*Communication:* Presented, Authored, Published, Wrote, Trained, Facilitated (use carefully), Advised, Consulted

*Results:* Increased, Decreased, Reduced, Grew, Improved, Accelerated, Delivered, Achieved, Exceeded, Generated, Saved, Cut

## AI Writing Patterns — Resume-Specific Flags

Beyond general AI vocabulary (covered by the 24-pattern catalog in `write`), these patterns appear specifically in AI-assisted resumes:

| Pattern | Example | Fix |
|---|---|---|
| Significance inflation in summary | "Transformative leader with a pivotal role in shaping the organizational landscape" | State what you actually did at what scale |
| Rule of three in bullets | "Developed, deployed, and maintained the system" | Pick the most important one or collapse to a single strong verb |
| Vague attribution | "Recognized for excellence in..." (by whom?) | Name the award, the person, the program |
| Forced parallelism that distorts truth | Making 3 bullets the same grammatical length when they aren't equal achievements | Let the most important bullet be longer |
| Generic summary closer | "Excited to bring my expertise to a forward-thinking organization" | Cut entirely or replace with a specific type of role/problem they want to work on |
| Em dash overuse in summary | "Results-driven professional — with 8+ years — who excels at..." | Restructure into clean sentences |
| Nominalization | "Provided assistance in the facilitation of..." | "Helped facilitate" or better, "Ran the..." |
| False precision | "Over 10 years of experience" when JD asks for 5+ | Fine if true; but don't add "+/-" hedging that undermines it |

## Metric-Free Bullets — The Most Common Problem

A bullet without a metric is a job description, not an achievement.

**No metric (weak):**
> Managed social media accounts across multiple platforms

**With metric (strong):**
> Managed Instagram, LinkedIn, and Twitter accounts, growing combined following from 12K to 41K in 14 months

**When no metric is available:**
Push the user with these questions:
- How many people used what you built/managed?
- What was the before vs. after on any measurable thing?
- What was the budget/headcount/scope?
- How much time did this save (even roughly)?
- What would have broken if you hadn't done it?

If truly no metric exists, write scope + action:
> Led end-to-end redesign of customer onboarding flow for 50K+ monthly active users (no conversion data available)

Transparency beats fabrication every time.

## Tense Rules

| Section | Tense | Exception |
|---|---|---|
| Current role | Present tense | If you're about to leave, past is fine |
| All past roles | Past tense | Always |
| Skills | No tense (noun list) | |
| Summary/Profile | Present tense (describes who you are now) | |
| Education | No tense (dates and credentials) | |

**Mixing tenses within a role is the most common error.** A bullet that starts "Led the team" and another that says "Manage vendor relationships" in the same role is jarring to human readers and signals carelessness.

## Formatting Language Rules

- No first-person pronouns ("I", "my", "we") — resumes are written in implied first-person
- No articles at the start of bullets ("A team of 5..." → "Team of 5..." or restructure)
- No periods at end of bullets (industry norm — periods are for prose, not resume bullets)
- No periods in the summary/profile section either, as a matter of convention, unless it's multiple full sentences (then periods are fine)
- Abbreviations: spell out on first use in full if it's not universally known. "SQL" is fine; "PLAID integration via OCPP using EVCS" needs expansion
